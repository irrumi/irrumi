## 🚀 Featured projects

### [stm32-mcp](https://github.com/irrumi/stm32-mcp)
**Give AI coding agents a headless interface to the STM32 toolchain.**

An MCP server for project creation, pin configuration, HAL code generation, compilation, diagnostics and hardware flashing using the official STMicroelectronics tooling.

TypeScript · MCP · STM32 · Embedded Systems · AI Agents

### [RulesKit](https://github.com/irrumi/RulesKit)
**One source of truth for instructions across AI coding agents.**

Generates and synchronizes project-specific instructions for Claude Code, OpenAI Codex, Gemini CLI, Cursor, GitHub Copilot and Windsurf from one reviewed configuration.

TypeScript · CLI · Developer Tools · AI Coding Agents

### [antigravity-plugin-codex](https://github.com/irrumi/antigravity-plugin-codex)
**Connect Codex with Antigravity for reviews, second opinions and delegated coding tasks.**

A local bridge that lets Codex invoke the Antigravity CLI while keeping Codex as the coordinating agent.

Node.js · MCP · Codex · Antigravity · Multi-Agent

### [RepoPolish](https://github.com/irrumi/RepoPolish)
**Static verification for repository documentation.**

An offline CLI that detects broken Markdown links, stale package-script examples and documentation drift, with evidence-based findings and safe fix previews.

TypeScript · CLI · Static Analysis · Developer Experience

### [Cerebrum — HackAlem AI](https://github.com/BAITC-Hacks/hack-deb8a427-cerebrum)
**AI-assisted telecom marketing campaign optimization.**

A hackathon project that experiments with customer segments, tariff migrations and communication channels under strict budget and contact constraints.

Python · AI Agents · Data Analysis · Telecommunications
